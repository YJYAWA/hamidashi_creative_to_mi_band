# 烘焙与体积实验数据

本文件记录为确定「表情怎么存」和「体积超在哪」所做的全部实测。数据来自本作（ハミダシクリエイティブ），可作为同类项目的起点参考。

---

## 1. 结论先行

1. **表情体积的主开关是 alpha 级数，不是烘焙方式。**
2. 差量烘焙在同级 alpha 下比墨色层**更大**，覆盖率还**更低**。
3. **闭嘴唇线的原始 alpha 只有 11/255**，必须在量化前提亮，否则直接被抹成 0。
4. **安装失败的判据是解压后体积**，不是 rpk 包体积。

---

## 2. alpha 级数实验

同一批 12 张高频表情，32 色调色板，墨色层烘焙：

| alpha 级数 | 单张 | 1340 张合计 | 说明 |
|---|---|---|---|
| 8 级 | 2051 B | 2.62 MiB | 边缘最平滑 |
| 6 级 | 1718 B | 2.20 MiB | |
| 4 级 | 1621 B | 2.07 MiB | |
| 3 级 | 1431 B | 1.83 MiB | |
| 2 级（二值） | 1157 B | 1.48 MiB | 硬边，v27 实际取值 |

> 每降一级约省 0.2~0.4 MiB / 1340 张。这是唯一能大幅调整表情体积的旋钮。

## 3. 烘焙方式对比

### 3.1 定义

- **差量烘焙**：把表情按真实偏移合成到身体上，只保留「与身体 RGB 差异 > 阈值」的像素，颜色取合成后的颜色，alpha 二值化。因为像素里混了身体色，**同一表情挂不同身体 = 不同图**。
- **墨色层**：表情按真实偏移贴到透明画布，颜色取原画墨色。**与身体无关**，可跨身体去重。

### 3.2 同参数（1340 张 / 32 色 / 2 级 alpha）实测

| 指标 | 差量烘焙 | 墨色层 |
|---|---|---|
| 唯一表情数 | 3611 | 2798 |
| 单张（3 级 alpha） | 1584 B | 1431 B |
| 单张（2 级 alpha） | ~1250 B | 1157 B |
| 1340 张合计（2 级） | ~1.60 MiB | 1.48 MiB |

**差量烘焙在同级下更贵**：因为它的像素颜色复杂（含身体色渐变），PNG 更难压。

### 3.3 覆盖率对比（1340 张 / 诗樱 72% / 里砍半 / 1:1:2）

| 角色 | 差量烘焙 | 墨色层 |
|---|---|---|
| 整体 | 79.7% | **85.9%** |
| 华乃 | 82.2% | 90.9% |
| 妃爱 | 82.1% | 89.6% |
| 明日美 | 84.3% | 90.9% |
| 诗樱 | 73.5% | 74.3% |
| 老师(里) | 66.7% | 73.8% |
| 龙闲 | 78.6% | 84.6% |
| 广梦 | 85.9% | 91.6% |

差量少 6.2 个百分点：它把唯一表情数从 2798 抬到 3611，同样的 1340 张预算能覆盖的台词行就少了。

> 注：v28 日志里的 74.3% 是**未加 1:1:2 配额**（全局按台词行贪心）的数字，加配额后可救到 79.7%。

## 4. 差量阈值实验

12 张样本，32 色 × 2 级 alpha：

| 阈值 `DELTA_THR` | 单张 | 保留像素 | 1340 张合计 |
|---|---|---|---|
| 8 | 1416 B | ~772 | 1.81 MiB |
| 16 | 1346 B | ~590 | 1.72 MiB |
| 24 | 1292 B | ~490 | 1.65 MiB |
| 32 | 1245 B | ~466 | 1.59 MiB |

阈值提到 32 也只省 0.22 MiB，但表情会退化成「只剩轮廓」。**性价比很低**，不建议用它调体积。

## 5. 覆盖率口径

必须按**台词行**统计，不能按出场次数。

```python
# 正确：统计每个表情覆盖了多少句台词
for scene in scenes:
    cur = None
    for op in scene['ops']:
        if op[0] == 'g':        # 立绘切换
            cur = op[2]
        elif op[0] == 't':      # 台词
            if cur: hash_lines[face_hash[cur]] += 1
```

同一个 sprite 可能出场 300 次却只配 2 句台词。按出场次数排序会把预算浪费在「站着不说话」的表情上。

## 7. 安装体积实测

| 版本 | rpk 包 | 解压 | 文件数 | 结果 |
|---|---|---|---|---|
| v8 | 20.15 | 23.75 | 7313 | 失败 |
| v9 | 18.94 | 22.51 | 5763 | 失败 |
| v26 | 15.31 | 18.87 | 3116 | **成功** |
| v27 | 15.72 | 19.23 | 3116 | **成功** |
| v29 | 16.72 | 20.31 | 3116 | 失败 |
| v30 | 17.34 | 21.02 | 3476 | 失败 |
| v31 | 16.73 | 20.33 | 3116 | 失败 |
| v32 | 15.69 | 19.18 | 2876 | **成功** |

**两条独立的红线**：解压体积（≈20 MiB）+ 文件数（3116 可用，3476 已失败）。
rpk 包体积与安装成败**无关**——v31 只有 16.73 MiB 却装不上。
